# 스마트 알약/영양제 디스펜서 웹 시뮬레이터

정적 HTML/CSS/JavaScript로 만든 제작 전 설계 검토용 웹앱입니다.

공개 페이지: https://estona815.github.io/smart-pill-sim-website/

## 현재 설계 전제

- Raspberry Pi 5와 9인치 HDMI 터치스크린을 사용합니다.
- 외장 모터 드라이버와 별도 원점 보정 센서는 현재 구성에서 제외합니다.
- 구동부는 특정 스텝모터로 단정하지 않고, 구동각 제어가 가능한 서보형 회전 구동부 또는 단순 회전 모듈로 추상화합니다.
- IR Break Beam 센서, 회전 슬롯 휠, 알약 저장통, 배출구, 상부 차단판, 3D 프린팅 구조물을 기준으로 합니다.
- 결과는 완성품 보증이 아니라 제작 전 위험 선별용 규칙/확률 기반 판단입니다.

## 주요 기능

- 알약 크기, 슬롯, 배출구, 경사각, 마찰, 공차, 구동부, IR 센서 조건 입력
- 정확 배출, 미배출, 중복 배출, 걸림, 센서 감지 실패, 구동 위치 오차 확률 계산
- 개선 전/후 성공·실패율 비교
- 실패 원인 Top 3 표시
- 현재 설계 구동 가능성 판단
- 권장 부품 수정안 표시
- 설계 전 체크리스트 표시
- CSV, JSON, PNG 저장

## 실행 방법

파일을 바로 열어도 동작합니다.

```bash
open index.html
```

로컬 서버로 실행하려면:

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.

## 사용 흐름

1. `예시값 불러오기`로 기준 조건을 확인합니다.
2. 실제 알약 치수와 슬롯/배출구 치수를 입력합니다.
3. 구동 방식, 전원 안정성, 백래시, 센서 위치를 조정합니다.
4. `반복 시뮬레이션 실행`으로 실패 유형을 확인합니다.
5. `개선 전/후 자동 비교`로 구조 개선 효과를 확인합니다.
6. 설계 가능성 판단, 권장 부품 수정안, 체크리스트를 보고 제작 전 보완점을 정리합니다.

## 주의

이 웹앱은 실제 물리엔진이나 의료기기 검증 도구가 아닙니다. 실제 제작 후에는 알약 표면 상태, 마찰, 토크, 센서 위치, 반복 구동 오차를 실물 테스트로 보정해야 합니다.
