# 스마트 알약/영양제 디스펜서 웹 시뮬레이터

## 목적

이 웹앱은 취약계층용 스마트 캡슐 알약 디스펜서 제작 전에 배출 오차를 가상 검증하기 위한 발표·보고서용 데모입니다. 실제 물리엔진이 아니라, 입력값을 바탕으로 미배출, 중복 배출, 알약 걸림, 센서 감지 실패, 모터 회전각 오차를 규칙·확률 기반으로 계산합니다.

핵심 메시지:

> 가상 검증을 통해 제작 오차를 줄이는 스마트 알약 자동 분배 시스템

## 실행 방법

가장 쉬운 방법:

1. `index.html` 파일을 더블클릭합니다.
2. 브라우저에서 시뮬레이터가 열립니다.
3. 예시값을 불러오거나 실제 치수를 입력합니다.
4. `1회 배출 애니메이션`, `반복 시뮬레이션 실행`, `개선 전/후 자동 비교`를 누릅니다.

로컬 서버로 실행하고 싶으면 Python이 설치된 폴더에서 다음 명령을 사용합니다.

```bash
python -m http.server 8000
```

그 뒤 브라우저에서 `http://localhost:8000`으로 접속합니다.

- 구비 부품/요구사항 메모

- 알약 지름/길이/무게
- 알약 저장량
- 저장통 경사각
- 마찰 계수
- 3D 프린팅 공차
- 슬롯 크기
- 슬롯 개수
- 휠 반지름
- 배출구 폭
- 출구 모서리 보정 여부
- 상부 차단판 여부
- 모터 속도
- 1회 회전각
- 모터 오차

- 목표 배출 수량
- 반복 횟수
- 개선 전/후 모드

## 안전한 제어 로직 입력

브라우저에서 임의 JavaScript를 실행하지 않고, 아래와 같은 `key=value` 형식만 해석합니다.

```text
retry=1
motorRamp=0.75
doubleDetect=true
sensorCheck=true
homeSensor=true
alarmOnFail=true
```

의미:

- `retry`: 미배출 상황에서 재시도 횟수. 0~3 권장.
- `motorRamp`: 모터 가감속 적용 정도. 0~1.
- `doubleDetect`: 중복 배출을 센서가 2회로 구분한다고 가정할지 여부.
- `sensorCheck`: 센서 확인 로직 사용 여부.
- `homeSensor`: A3144 홀센서 원점 보정 사용 여부.
- `alarmOnFail`: 실패 시 화면 안내/경고 사용 여부.

## 발표자료 활용 방법

1. 예시값을 불러옵니다.
2. `개선 전/후 자동 비교`를 실행합니다.
3. `반복 시뮬레이션 실행`으로 결과 수치를 표시합니다.
4. `장면 PNG 저장`으로 정상/실패 장면을 캡처합니다.
5. 그래프와 표를 발표자료에 삽입합니다.

추천 발표 문장:

> 본 시뮬레이터는 알약 크기, 슬롯 크기, 배출구 폭, 모터 회전각, 센서 위치를 입력값으로 받아 배출 실패 유형을 사전에 예측한다. 이를 통해 실제 3D 프린팅 전에 미배출, 중복 배출, 걸림, 센서 감지 실패 가능성을 확인하고 구조 개선 근거를 확보하였다.

## 주의사항

- 실제 알약의 충돌, 마찰, 회전, 변형을 완전히 계산하는 DEM 물리 시뮬레이터는 아닙니다.
- 발표와 설계 검토용 간이 디지털 트윈으로 사용하세요.
- 실제 제작 후에는 배출 실험 데이터를 넣어 확률식을 보정하는 것이 좋습니다.
- 의약품을 실제로 취급하는 제품은 안전성, 위생, 사용자 오류 방지, 법적 기준 검토가 필요합니다.
