# 스마트 알약/영양제 디스펜서 웹 시뮬레이터

## 목적

이 웹앱은 취약계층용 스마트 캡슐 알약 디스펜서 제작 전에 배출 오차를 가상 검증하기 위한 발표·보고서용 데모입니다. 실제 물리엔진이 아니라, 입력값을 바탕으로 정확 배출, 미배출, 중복 배출, 알약 걸림, 센서 감지 실패, 구동 위치 오차를 규칙·확률 기반으로 계산합니다.

핵심 메시지:

> 가상 검증을 통해 제작 오차를 줄이는 스마트 알약 자동 분배 시스템

현재 하드웨어 전제는 외장 모터 드라이버와 원점 보정 센서를 쓰지 않는 구성입니다. 구동부는 특정 스텝모터로 단정하지 않고, 서보형 회전 구동부 또는 단순 회전 모듈 기반 슬롯 휠로 추상화합니다.

## 실행 방법

가장 쉬운 방법:

1. `index.html` 파일을 더블클릭합니다.
2. 브라우저에서 시뮬레이터가 열립니다.
3. 예시값을 불러오거나 실제 치수를 입력합니다.
4. `1회 배출 애니메이션`, `반복 시뮬레이션 실행`, `개선 전/후 자동 비교`를 누릅니다.

로컬 서버로 실행하고 싶으면 Python이 설치된 폴더에서 다음 명령을 사용합니다.

```bash
python -m http.server 8000
```

그 뒤 브라우저에서 `http://localhost:8000`으로 접속합니다.

## 입력 가능한 정보

- 프로젝트명
- 구비 부품/요구사항 메모
- 알약 형태: 원형, 타원형, 캡슐형
- 알약 지름/길이/무게
- 알약 저장량
- 저장통 경사각
- 마찰 계수
- 3D 프린팅 공차
- 슬롯 크기
- 슬롯 개수
- 휠 반지름
- 배출구 폭
- 출구 모서리 보정 여부
- 상부 차단판 여부
- 구동 방식: 서보형 회전 구동부, 단순 회전 모듈, 수동 가상 입력
- 동작 속도
- 1회 구동각
- 구동각 오차
- 기구 유격/백래시
- 전원 안정성 수준
- IR 센서 위치, 감지 범위, 반응 시간, 디바운스 시간
- 목표 배출 수량
- 반복 횟수
- 개선 전/후 모드

## 안전한 제어 로직 입력

브라우저에서 임의 JavaScript를 실행하지 않고, 아래와 같은 `key=value` 형식만 해석합니다.

```text
retry=1
motorRamp=0.75
doubleDetect=true
sensorCheck=true
alarmOnFail=true
jamRecovery=false
```

의미:

- `retry`: 미배출 상황에서 재시도 횟수. 0~3 권장.
- `motorRamp`: 구동부 가감속 적용 정도. 0~1.
- `doubleDetect`: 중복 배출을 센서가 2회로 구분한다고 가정할지 여부.
- `sensorCheck`: 센서 확인 로직 사용 여부.
- `alarmOnFail`: 실패 시 화면 안내/경고 사용 여부.
- `jamRecovery`: 걸림 완화 동작이 있다고 가정할지 여부.

## 발표자료 활용 방법

1. 예시값을 불러옵니다.
2. `개선 전/후 자동 비교`를 실행합니다.
3. `반복 시뮬레이션 실행`으로 결과 수치를 표시합니다.
4. `장면 PNG 저장`으로 정상/실패 장면을 캡처합니다.
5. 그래프와 표를 발표자료에 삽입합니다.

추천 발표 문장:

> 본 시뮬레이터는 알약 크기, 슬롯 크기, 배출구 폭, 저장통 경사각, 마찰, 구동각 오차, 센서 조건을 입력값으로 받아 배출 실패 유형을 사전에 예측한다. 정확 배출률을 임의로 높이는 도구가 아니라, 구조 개선 조건을 넣었을 때 실패 확률이 어떻게 줄어드는지 비교해 실제 제작 전 보완 근거를 확보하는 도구이다.

## 주의사항

- 실제 알약의 충돌, 마찰, 회전, 변형을 완전히 계산하는 DEM 물리 시뮬레이터는 아닙니다.
- 발표와 설계 검토용 간이 디지털 트윈으로 사용하세요.
- 실제 제작 전에는 반드시 실물 배출 실험 데이터를 넣어 확률식을 보정해야 합니다.
- 외장 구동 드라이버와 별도 원점 보정 센서는 현재 설계 범위에서 제외합니다.
- 의약품을 실제로 취급하는 제품은 안전성, 위생, 사용자 오류 방지, 법적 기준 검토가 필요합니다.
